# okx-options-bot

Каждые 15 минут анализирует опционы BTC/ETH на OKX и ведёт **виртуальную
(paper) торговлю**: на каждый непустой сигнал открывает симулированную
позицию на $5 в ATM-опционе по реальным bid/ask ценам OKX, закрывает её на
следующем цикле (~15 мин) и считает P&L. Статистика (win rate, W/L, серии,
просадка, equity-кривая, таблица ставок) отдаётся веб-дашбордом.

Это **не торговый бот** — реальных ордеров бот никогда не размещает,
торгует только "на бумаге" собственным виртуальным балансом, используя
реальные рыночные цены OKX для честного расчёта P&L. Bias-сигнал
("Bullish"/"Bearish"/"Neutral") — простая эвристика, не финансовый совет.

## Как это работает

Раз в 15 минут (`POLL_INTERVAL_SECONDS`, по умолчанию 900с), для каждого
символа из `SYMBOLS`:

1. **Закрывает** открытую с прошлого цикла позицию (если есть) — берёт
   текущий `bidPx` опциона (`/api/v5/market/ticker`), считает стоимость
   позиции в USD и P&L относительно ставки.
2. **Технический анализ** базового актива — свечи `{SYMBOL}-USDT` бар 15m:
   RSI(14), MACD(12,26,9), EMA9/EMA21.
3. **Метрики опционного рынка** — сводка по `{SYMBOL}-USD`
   (`/api/v5/public/opt-summary`) для ближайшей экспирации: ATM implied
   volatility, 25-delta skew, put/call open interest ratio, OI-взвешенные
   греки.
4. Считает эвристический **bias** (Bullish/Bearish/Neutral) из технических
   и опционных сигналов.
5. Если bias не Neutral — **открывает** новую позицию: ATM call (Bullish)
   или ATM put (Bearish) ближайшей экспирации, размер позиции подбирается
   так, чтобы стоимость входа была ≈ `STAKE_USD` (по `askPx`).

Контракты OKX могут быть маржированы в USD/USDT/USDC (премия уже в
долларах) или в монете базового актива (премия в BTC/ETH) — конвертация в
USD учитывает `ctVal`/`ctValCcy` инструмента и текущий спот.

## Настройка

```bash
cp .env.example .env
# опционально: OKX_API_KEY/SECRET/PASSPHRASE (read-only!) для более
# высокого rate-limit — без них бот работает на публичных эндпоинтах OKX
docker compose up -d --build
```

Дашборд: `http://<host>:8000` (порт настраивается через `HTTP_PORT`).
У интерфейса нет встроенной аутентификации — ограничивай доступ на уровне
сети/firewall/VPN, если разворачиваешь на публичном VPS.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `OKX_BASE_URL` | `https://www.okx.com` | REST endpoint OKX |
| `OKX_API_KEY` / `OKX_API_SECRET` / `OKX_API_PASSPHRASE` | пусто | опционально, только read-only доступ |
| `SYMBOLS` | `BTC,ETH` | список базовых активов через запятую |
| `CANDLE_BAR` | `15m` | таймфрейм свечей |
| `CANDLE_LIMIT` | `150` | сколько свечей запрашивать для индикаторов |
| `POLL_INTERVAL_SECONDS` | `900` | интервал цикла анализа/торговли (15 мин) |
| `STAKE_USD` | `5.0` | размер виртуальной ставки на сигнал |
| `STARTING_BANKROLL` | `1000.0` | стартовый виртуальный баланс для дашборда |
| `DB_PATH` | `./data/bets.db` | путь к SQLite с историей ставок |
| `HTTP_HOST` / `HTTP_PORT` | `0.0.0.0` / `8000` | адрес веб-дашборда |
| `LOG_LEVEL` | `INFO` | уровень логирования |

## Тесты

```bash
pip install -r requirements.txt
pytest
```

Тесты полностью офлайн: HTTP к OKX мокается через `respx`/фейковый клиент,
веб-API проверяется через `fastapi.testclient.TestClient`, реальные
сетевые вызовы не выполняются.

## Важно

Схема эндпоинтов OKX v5 (`/api/v5/market/candles`, `/api/v5/market/ticker`,
`/api/v5/public/instruments`, `/api/v5/public/opt-summary`,
`/api/v5/public/open-interest`) реализована по официальной документации
OKX и может со временем меняться на их стороне — перед тем как доверять
цифрам P&L, стоит сверить актуальные поля ответа (особенно `ctVal` /
`ctValCcy` для расчёта стоимости контракта в USD) с
https://www.okx.com/docs-v5/en/.
